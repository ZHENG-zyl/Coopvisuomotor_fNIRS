# Task-interface images

This directory contains one representative interface screenshot for each of the four experimental conditions. The filenames follow the fixed run order used throughout the dataset:

| Run | Collaboration mode | Target | Difficulty | File |
|---|---|---|---|---|
| 01 | Leader-follower | Carrot | Easy | `run-01_leader-follower_carrot_interface.png` |
| 02 | Leader-follower | Wave | Hard | `run-02_leader-follower_wave_interface.png` |
| 03 | Egalitarian | Carrot | Easy | `run-03_egalitarian_carrot_interface.png` |
| 04 | Egalitarian | Wave | Hard | `run-04_egalitarian_wave_interface.png` |

The screenshots document the visual target, displayed boards, and haptic workspace presented in each condition. The four PNG files contain no participant identifiers or experimental response data.
