# Technical-validation outputs

This directory contains the final machine-readable results reported in the Technical Validation section of the accompanying data descriptor.

- `behavioral/`: condition-level descriptive statistics, dyad-level means, and within-dyad statistical tests.
- `qc-hrf/`: channel- and trial-level quality control, excluded-channel listings, and channel-wise HbO/HbR HRF estimates.
- `wtc/`: WTC metrics for the 26 cross-participant channel pairs, true-versus-pseudo dyad comparisons, and WTC-behavior correlations.

CSV files contain the reported numeric results. JSON files record the analysis settings. Publication figures are presented in the accompanying article and are not duplicated here.
